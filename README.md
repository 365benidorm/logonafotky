# Logo na fotky

Webová appka, která přidá logo Benidorm Expats na fotky. Fotky ořízne do formátu pro Instagram a logo umístí tam, kde fotku nejméně ruší.
Na každou fotku můžeš přidat text, samolepky (Benidorm sada, emoji, vlastní PNG) a filtr.
Všechno běží v prohlížeči. Fotky se nikam neodesílají.

Běží na https://365benidorm.github.io/logonafotky/
Na telefonu: otevři adresu → menu prohlížeče → *Přidat na plochu*.
