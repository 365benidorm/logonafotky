# Logo na fotky

Webová appka, která přidá logo Benidorm Expats na fotky. Fotky ořízne do formátu pro Instagram a logo umístí tam, kde fotku nejméně ruší.
Všechno běží v prohlížeči. Fotky se nikam neodesílají.

## Nasazení na GitHub Pages
1. Vytvoř nový repozitář (např. `logo-na-fotky`) a nahraj do něj obsah této složky.
2. Settings → Pages → Source: *Deploy from a branch*, větev `main`, složka `/ (root)`.
3. Za chvíli poběží na `https://<tvuj-ucet>.github.io/logo-na-fotky/`.
4. Na telefonu: otevři adresu → Sdílet → *Přidat na plochu*.
